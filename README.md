# Chamados Project
Implementando grafico e site de chamados relacionado;
Usando css e html - 

## Overview

The application presents a user-friendly interface to view and manage chamados, including their titles, priorities, statuses, and assigned users.

## Project Structure

```
chamados
├── index.html        # Main HTML document for the website
├── css
│   └── styles.css    # Stylesheet for the website
└── README.md         # Documentation for the project
```

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the application.
3. Modify the `css/styles.css` file to customize the appearance of the website as needed.
